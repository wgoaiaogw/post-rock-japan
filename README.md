# POSTROCK JAPAN

日本のポストロック／マスロック／インストゥルメンタル・ロックの公演情報を、公式情報源に基づいてまとめるサイト。

- 公演情報は楽隊公式サイト・会場公式ページ・公式チケットページで確認したものだけを掲載します
- 各公演ページに情報源 URL と確認日を明記します
- データは `data/` 以下の JSON ファイルで管理しています（公演は期間別に分割：events-2026-h1 / events-2026-h2 / events-2027、アーティスト：artists、会場：venues）

サイト: https://wgoaiaogw.github.io/post-rock-japan/
